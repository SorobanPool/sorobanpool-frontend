# Pidgin (pcm.json) Translation Changes

## [2026-11-21]

### Review Scope
- Pool state messaging and join panel interface
- Payment confirmation and transaction flow
- Error messages and user feedback
- Navigation and common UI labels

### Changes Made
All Pidgin strings have been reviewed for clarity, tone, and appropriate length for mobile (360px) screens. No strings were added or removed. The following review focused on:

1. **Clarity for non-native speakers**: Confirmed all strings use straightforward Pidgin without complex grammatical structures
2. **Length constraints**: Verified strings fit within 300 characters and wrap appropriately on 360px screens
3. **Consistency**: Maintained consistent tone and vocabulary across all sections
4. **Placeholders**: All placeholder markers ({count}, {price}, {amount}, etc.) remain unchanged

### Tone and Clarity Notes
- Payment-related strings emphasize safety and assurance (e.g., "Your money dey safe")
- Error messages use conversational Pidgin to feel approachable rather than technical
- Action buttons use imperatives that are clear and direct (e.g., "Pay now", "Confirm", "Try again")
- Navigation and status updates use simple, recognizable labels
- Financial values and amounts are presented clearly with currency context

### Notes for Future Translators
- The Pidgin translation uses present continuous tense liberally (e.g., "dey" for ongoing states)
- Idioms and colloquialisms are intentional and should be preserved to maintain tone
- Keep error messages brief and reassuring to reduce user anxiety
- Button labels should remain concise to avoid wrapping on mobile screens
